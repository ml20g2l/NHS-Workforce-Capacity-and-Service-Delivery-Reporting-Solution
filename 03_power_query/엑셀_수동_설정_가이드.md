# Excel Power Query 수동 설정 가이드

이 문서는 `power_query_control.xlsx`에 Power Query를 처음 등록하고
Phase 7 반복 보고 테스트를 실행하기 위해 **사용자가 Excel에서 직접 해야
하는 작업만** 한국어로 설명합니다.

## 먼저 알아둘 점

- `.pq` 파일과 검증 로직은 이미 작성되어 있습니다.
- Excel 파일 생성 도구는 새 Power Query 연결 객체를 워크북에 직접 넣을
  수 없습니다.
- 따라서 아래의 **최초 1회 쿼리 등록**은 Excel의 Advanced Editor에서
  수동으로 해야 합니다.
- 한 번 등록한 후에는 새 월 파일 추가와 새로고침이 반복 작업이 됩니다.
- 원본 파일은 수정하거나 이동하지 마세요.

## 1. 워크북 열기

1. Excel에서 `03_power_query/power_query_control.xlsx`를 엽니다.
2. `Parameters` 시트에서 `tblParameters` 표를 확인합니다.
3. 다음 여섯 행이 있는지 확인합니다.

| ParameterName | 초기값 |
|---|---|
| WorkforceFolder | `04_processed_data\staging\workforce`의 전체 경로 |
| AbsenceFolder | `02_source_data\raw\absence`의 전체 경로 |
| ActivityFolder | `02_source_data\raw\service_activity`의 전체 경로 |
| ReferenceFolder | `02_source_data\reference`의 전체 경로 |
| ReportingStartMonth | `2024-04-01` |
| ReportingEndMonth | `2025-03-01` |

프로젝트 폴더 위치가 현재와 같으면 경로를 변경할 필요가 없습니다.

## 2. 쿼리 한 개를 등록하는 방법

아래 작업을 쿼리마다 반복합니다.

1. Excel 상단에서 **데이터**를 선택합니다.
2. **데이터 가져오기 → 기타 원본에서 → 빈 쿼리**를 선택합니다.
3. Power Query 편집기 왼쪽의 새 쿼리를 마우스 오른쪽 버튼으로 누르고
   **이름 바꾸기**를 선택합니다.
4. 아래 표의 `쿼리 이름`을 정확하게 입력합니다.
5. **홈 → 고급 편집기**를 선택합니다.
6. 편집기에 들어 있는 기존 내용을 모두 지웁니다.
7. 아래 표의 해당 `.pq` 파일을 메모장으로 열고 전체 내용을 복사합니다.
8. Advanced Editor에 붙여넣고 **완료**를 선택합니다.
9. 오류가 없으면 다음 쿼리를 등록합니다.

대소문자와 이름을 임의로 변경하지 마세요. 다른 쿼리가 이 이름을
참조합니다.

## 4. 로드 방식 설정

쿼리를 등록한 후 Power Query 편집기에서:

1. **홈 → 닫기 및 다음으로 로드**를 선택합니다.
2. 위 표에서 `연결만 만들기`인 쿼리는 **연결만 만들기**를 선택합니다.
3. 결과 확인용 쿼리는 **표 → 새 워크시트**를 선택합니다.
4. 큰 staging/classified 쿼리를 전부 워크시트에 로드하지 마세요.
   Excel 행 제한과 파일 크기 문제가 생길 수 있습니다.

최소한 다음 네 결과 쿼리는 워크시트 표로 확인하는 것을 권장합니다.

- `qryPowerQueryExceptions`
- `qryPowerQueryRefreshSummary`
- `qrySourceFileRegister`
- `qryDataQualityReconciliation`

## 5. 최초 전체 새로고침

1. Excel로 돌아갑니다.
2. **데이터 → 모두 새로 고침**을 선택합니다.
3. **데이터 → 쿼리 및 연결**에서 새로고침이 끝날 때까지 기다립니다.
4. 빨간 오류 표시가 있는 쿼리가 없는지 확인합니다.
5. 결과 시트에서 다음을 확인합니다.

| 확인 항목 | 통과 조건 |
|---|---|
| 쿼리 수 | 31개 |
| 기간 | 2024-04부터 2025-03까지 |
| 조직 기준표 | 148개 안정 조직, London 포함 조직 20개 |
| 파일 등록 | 데이터셋·월별 Active 파일 1개 |
| 예외 | 사유와 원본 파일을 추적할 수 있음 |
| 조정 | Raw = Accepted + Review Required + Rejected |
| 보고 범위 | Reportable 수치가 별도로 표시됨 |

새로고침 오류가 나오면 오류 메시지를 캡처하여 Codex에 보내주세요.

## 사용자가 수동으로 해야 하는 부분 요약

1. Excel Advanced Editor에 31개 `.pq` 파일을 최초 1회 등록
2. 각 쿼리의 로드 방식을 설정
3. Excel에서 **모두 새로 고침** 실행
4. 오류가 있으면 오류 메시지 또는 화면 캡처 제공
5. 각 Cycle의 결과 쿼리를 지정 폴더에 저장

위 다섯 항목 외의 소스 파일 준비, Cycle 입력 생성, 해시 검증 및 통제
테스트 설계는 자동화되어 있습니다.
